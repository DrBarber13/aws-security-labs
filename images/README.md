# Public-evidence policy

This repository uses Mermaid diagrams, policy patterns, decision tables, and fictional timelines instead of screenshots from the coursework environment.

Screenshots are optional and must never expose account IDs, ARNs, real resource names, addresses, access keys, email addresses, billing data, browser profiles, or lab-provider content. A diagram or written validation record is preferred whenever redaction would remove the technical meaning of an image.
# Image checklist

Use only images from the independent rebuild:

- `architecture.png` - original AWS diagram
- `iam-validation.png` - fictional principal and redacted resource identifiers
- `network-validation.png` - security-group or reachability evidence
- `s3-versioning.png` - sanitized recovery evidence
- `cloudtrail-event.png` - redacted audit event

Remove account IDs, ARNs, access keys, email addresses, student IDs, public IP addresses, and lab-provider branding.
